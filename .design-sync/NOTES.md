# design-sync notes — watermark-web

- 2026-07-31: This repo is NOT a component library — it's a vanilla-JS single-page app (client-side image watermarking). No Storybook, no stories, no exported components, `dist/` is a Vite site build. User chose a **style-only sync**: tokens + fonts + CSS visual identity, no components. `shape: "style-only"` in config.json is a custom value — the stock converter (`package-build.mjs`) does not apply; the bundle is authored by hand to the upload format's style surface (`styles.css`, `tokens/`, `fonts/`, `README.md`).
- No `_ds_sync.json` anchor is produced (no components to hash) — a future re-sync re-verifies/re-uploads everything, which is cheap at this size.
- Fonts: Hanken Grotesk (400/500/600/700), Bricolage Grotesque (500/600/700), JetBrains Mono (400/500) — the app loads them from Google Fonts; the bundle vendors them as woff2 (latin subset) under `fonts/` with `@font-face` in `fonts/fonts.css`, imported from `styles.css`. Bricolage and Hanken are variable fonts (one file each, weight-range @font-face); JetBrains Mono is static per weight.
